# タイムズカー自動予約

土日の 9:00〜21:00 を、予約受付が開く0時ちょうどに2週間先で自動予約する。
前日夜にiPhoneへ「使う／キャンセル」ボタン付きの通知を送り、「使う」が押されなかった予約は当日朝8時ごろに自動キャンセルする。

すべてGitHub Actions上で動くので、PCやClaudeを開いておく必要はない。

## スケジュール（日本時間）

| 時刻 | 処理 |
|---|---|
| 毎日 23:45 | 起動して0:00まで待機 → 14日先が土日なら優先順に予約（予備 0:25） |
| 金・土 20:47 | 明日の自動予約に「使う／キャンセル」ボタン付き通知 |
| 土・日 8:05 | 「使う」が押されていない自動予約を取消（予備 8:25・8:45） |

## ステーションの優先順位

`config.yaml` の `stations` を参照。tier1 は上から順、tier2 はどちらでも、tier3 は全滅時のみ。

## iPhoneからの操作

- **通知のボタン**：ntfyアプリの通知にある「使う」「キャンセル」をタップ
- **操作パネル**：`docs/index.html`（GitHub Pages）。予約一覧の確認・個別予約・キャンセル
- **GitHubアプリ**：Actions → 「iPhoneからの操作」→ Run workflow

## Secrets

| 名前 | 内容 |
|---|---|
| `TIMES_ID` | タイムズカー会員番号（IC管理番号、10桁） |
| `TIMES_PW` | タイムズカーのパスワード |
| `NTFY_TOPIC` | ntfyのトピック名（推測されにくい文字列） |
| `GH_PAT` | このリポジトリだけに権限を絞ったFine-grained token（Contents: Read and write） |
