# タイムズカー自動予約

土日の 9:00〜21:00 を、予約受付が開く0時ちょうどに2週間先で自動予約する。
前日夜にiPhoneへ「使う／キャンセル」ボタン付きの通知を送り、「使う」が押されなかった予約は当日朝8時ごろに自動キャンセルする。

タイムズのサイトはクラウドのサーバーからのアクセスを受け付けないため、自分のPC（Windows）のタスクスケジューラで動かす。

## 導入

1. フォルダ一式をPCに置き、`setup.bat` をダブルクリック
2. 会員番号とパスワードを入力（Windowsの資格情報マネージャーに保存）
3. iPhoneに「接続テスト成功」が届けば完了

やめるときは `uninstall.bat`。

## スケジュール（タスクスケジューラ「Timescar」フォルダ）

| 時刻 | 処理 |
|---|---|
| 毎日 23:50 | 0:00まで待機 → 14日先が土日なら優先順に予約 |
| 金・土 20:47 | 明日の自動予約に「使う／キャンセル」ボタン付き通知 |
| 土・日 8:05 / 8:25 / 8:45 | 「使う」が押されていない自動予約を取消 |
| 5分おき | iPhoneから届いた操作を実行 |

PCがスリープ中でも起こして実行する設定。電源が切れている・ログオフしているときは動かない。

## iPhoneからの操作

- 通知の「使う」「キャンセル」ボタン
- 通知をタップすると開く操作パネル（`docs/index.html`）：予約一覧・個別予約・キャンセル
- 操作は ntfy のコマンド用トピックに送られ、PCが5分おきに読み取って実行する

## ステーションの優先順位

`config.yaml` の `stations`。tier1 は上から順、tier2 はどちらでも、tier3 は全滅時のみ。
